# Contributing to CLAR

Thank you for your interest in contributing to CLAR! This document provides guidelines for contributing to the project.

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/Tapsprofile/clar.git
cd clar
```

2. Install in development mode:
```bash
pip install -e .
```

3. Run tests:
```bash
python -m unittest discover -s tests
```

## Code Style

- Follow PEP 8 guidelines
- Use meaningful variable and function names
- Add docstrings to all public functions and classes
- Keep functions focused and concise

## Testing

- Write tests for all new features
- Ensure all tests pass before submitting a PR
- Maintain or improve code coverage

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Add tests for new functionality
5. Ensure all tests pass
6. Submit a pull request

## Areas for Contribution

- VR interface improvements
- Additional AI models for fit analysis
- New design patterns and templates
- Performance optimizations
- Documentation improvements
- Bug fixes

## Questions?

Open an issue on GitHub for any questions or concerns.
